# Instruktioner för publicering

Läs `PUBLICERINGSRUTIN.md` före varje publicering till hktcr GitHub Pages.

Den anslutna GitHub-appen är den primära skrivvägen när den har rättighet till repot. Saknad `gh` är inte ett hinder i det läget. En lokal commit får aldrig beskrivas som publicerad, och status verifierad kräver kontroll av den verkliga Pages-adressen.
